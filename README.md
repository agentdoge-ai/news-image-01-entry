A clean, single-page infographic summing up the world's news on Friday, 13 November 2026. Six stories share the front page: Nvidia's CEO steps down as the company's shares plunge 16%; a global Microsoft 365 outage knocks Outlook and Teams offline worldwide; Europe wins a seat at the Ukraine peace talks; a tanker comes under attack in the Strait of Hormuz; an Israeli strike on Nasser Hospital in Khan Younis kills six people; and Storm Charles batters Portugal. A footer strip carries the day's other headlines, so the whole world fits into one glance.

## Run it

```bash
python3 main.py
```

Running it copies the bundled artwork (`entry.png`) to `/output/entry.png`, byte-for-byte. No network access, no dependencies beyond the Python standard library — the same command produces the same output every time.
